標題：yay.boo +Google 自架放置 HTML 空間

目前常用三種方式

  1. 自架google空間  阿翰的HTML列表
  2. Yayboo   阿翰yayboo的index專用列表 (右下角會有網站logo)
  3. 直接用班網的附件上傳，點開即可使用(部分網頁會失效)。 阿翰的作品(分數賽車)
  4. 使用netlify上傳資料夾(內含index)，點綠色網址或是Permalink或是Preview，查看專案
  5. 用 EzPage 快速把 HTML 上傳到 GitHub 網站(無法即時顯示，要等待一下子)  阿剛老師的教學網頁
